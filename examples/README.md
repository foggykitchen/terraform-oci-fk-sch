# Examples

This directory contains small examples showing how to compose **`terraform-oci-fk-sch`** in practical OCI event-driven scenarios.

Current examples:

- [`01_stream_to_function`](01_stream_to_function)  
  Minimal **OCI Streaming -> OCI Functions** Service Connector

- [`02_explicit_connector_name`](02_explicit_connector_name)  
  Same connector pattern with explicit display name and description overrides

These examples focus only on the **Service Connector Hub** layer.
They assume the referenced **stream** and **function** already exist or are created elsewhere in the same stack.
